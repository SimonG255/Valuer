# Valuer
Analitična in razvojna naloga za študentsko delo pri Valuer.si

Navodila:
1. Analitična naloga

Za potrebe izbora najustreznejšega kandidata lahko do 16. 6. 2026 pripravite strokovno poročilo o vplivu starosti in obnov enostanovanjske hiše na njeno tržno vrednost na podlagi podatkov o izvedenih transakcijah, do katerih dostopate v sklopu »Analiza trga« na portalu Valuer.si.

V poročilu pričakujemo predvsem:

analizo vpliva starosti in obnov hiše na doseženo tržno vrednost stanovanjske hiše,
prikaz uporabljene metodologije in kriterijev izbora,
grafični in tabelarični prikaz ključnih ugotovitev,
interpretacijo rezultatov ter zaključke analize.
Zaželeno je tudi, da podate:

predloge za izboljšavo spletnega sistema Valuer.si,
morebitne predloge novih funkcionalnosti,
opažanja glede uporabniške izkušnje, preglednosti podatkov in analitičnih možnosti sistema.
2. Razvojna naloga

Naloga je izdelava preproste spletne aplikacije za upravljanje cenitev nepremičnin.

Pri izdelavi naj se uporabi:

PHP
MySQL
HTML/CSS
JavaScript
Aplikacija naj vsebuje naslednje funkcionalnosti:

Registracija uporabnika

ime,
priimek,
email,
geslo.
Prijava uporabnika

prijava z email naslovom in geslom.
Upravljanje cenitev

Po prijavi naj ima uporabnik možnost:

dodajanja cenitve,
urejanja cenitve,
brisanja cenitve,
pregleda vseh cenitev.
Cenitev naj vsebuje naslednje podatke:

naziv naročnika – ročni vnos,
naslov naročnika – ročni vnos,
namen cenitve – izbira:
zavarovano posojanje,
sodni postopek,
stečajni postopek,
računovodsko poročanje,
davčni postopek,
poslovna odločitev naročnika,
podlaga vrednosti – izbira:
tržna vrednost,
likvidacijska vrednost,
tržna najemnina,
pravična vrednost,
premisa vrednosti – izbira:
sedanja ali obstoječa uporaba,
najgospodarnejša uporaba,
redna likvidacija,
prvi ogled (datum in ura) – date/time format.
Dodatne zahteve

uporaba MySQL baze,
pripravljena SQL skripta za kreiranje baze,
smiselna struktura kode,
osnovna validacija podatkov,
brisanje cenitve brez osvežitve celotne strani (AJAX/fetch).
Dodatne točke

uporaba Git repozitorija,
dodatne funkcionalnosti,
boljša uporabniška izkušnja,
pregledna in strukturirana koda.
